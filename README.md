# Dungeon Planner

An addon for **WoW Forever**: dungeon quests, secret quests, loot, maps and routes to every dungeon, in 10 languages.

## Install

1. Click the green **Code** button above, then **Download ZIP** (or grab the newest zip under **Releases**).
2. Open the zip and copy the `DungeonPlanner` folder into the `Interface/AddOns` folder of your WoW Forever install.
3. Restart the game. Type `/dp` in chat to open it.

## Found a problem?

Open an issue: click **Issues** at the top, then **New issue**, then **Report a problem**. In the game, `/dp bug` gives you text you can paste into it.

## Send quest data

Dungeon Planner can show the real XP and rewards WoW Forever pays for each quest, but we need players' help to get every number right.

With your yes, the addon notes what the game shows you for quests. When there's enough to share, a small **Share quest data** button shows up in an inn or city. Click it, copy the text, and paste it into the form it links to (**Issues → New issue → Send quest data**). Only game numbers are included (quest, level, XP, money, rewards); never your character, account or guild name.
